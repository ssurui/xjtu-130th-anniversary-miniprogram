# 西安交通大学130周年校庆小程序 - 需求规格说明

版本：1.0
日期：2026年3月
项目：西安交通大学130周年校庆活动微信小程序

---

## 1. 项目背景

西安交通大学（简称西交大，XJTU）建校于1896年，2026年迎来建校130周年。为庆祝这一重要节点，学校策划通过礼品赠送的方式与校友、学生和社会人士互动，通过微信小程序实现数字化校庆纪念品发放。

用户扫描礼品盒卡片上的微信二维码后，进入小程序，可获得专属VIP纪念卡，并参与一次性校庆抽奖活动，赢取礼券。

---

## 2. 术语定义

| 术语 | 定义 |
|------|------|
| openid | 用户在小程序内的唯一标识，由微信平台分配 |
| VIP卡 | 小程序内的虚拟纪念卡，展示卡号和礼券余额 |
| scene参数 | 微信小程序码携带的附加参数，用于区分礼品类型 |
| 礼券 | 电子优惠券，以元为单位，可用于兑换实体礼品 |
| 云开发 | 微信云开发平台，提供数据库、云函数、云存储服务 |

---

## 3. 功能需求列表

### REQ-001：二维码扫描进入小程序
- **描述**：用户扫描礼品盒卡片上的微信小程序码，进入小程序
- **优先级**：P0（核心需求）
- **验收标准**：扫码后3秒内进入小程序首页

### REQ-002：不同二维码区分礼品类型
- **描述**：不同礼品盒对应不同小程序码，小程序能识别并展示对应礼品信息
- **优先级**：P0（核心需求）
- **实现方式**：小程序码携带`scene`参数（`gift1`或`gift2`）
- **验收标准**：扫描`gift1`码进入显示文化衫，扫描`gift2`码进入显示帆布包

### REQ-003：首页展示校庆图案
- **描述**：首页展示西安交通大学130周年校庆横幅图案
- **优先级**：P1
- **验收标准**：进入首页可看到校庆Banner图

### REQ-004：VIP卡展示
- **描述**：首页展示专属VIP卡，包含卡号（格式：XJTU-XXXXXX）和礼券余额
- **优先级**：P0
- **验收标准**：
  - 未登录显示默认值：卡号`XJTU-000000`，余额`¥10`
  - 登录后显示真实卡号和余额

### REQ-005：礼品类型展示
- **描述**：首页根据扫码类型展示对应的礼品图片和名称
- **优先级**：P1
- **验收标准**：礼品图片和名称与扫码类型匹配

### REQ-006：抽奖入口展示
- **描述**：首页展示抽奖入口按钮，引导用户参与抽奖
- **优先级**：P0
- **验收标准**：首页可见"立即抽奖"或"登录参与抽奖"按钮

### REQ-007：一键登录授权
- **描述**：用户点击登录按钮，弹出微信手机号授权弹窗，完成一键登录
- **优先级**：P0
- **实现方式**：`<button open-type="getPhoneNumber">`
- **验收标准**：真机点击按钮弹出微信授权弹窗，用户授权后完成登录

### REQ-008：获取用户信息
- **描述**：系统自动获取用户openid，用户授权后获取手机号
- **优先级**：P0
- **验收标准**：
  - openid无需授权自动获取
  - 手机号经用户授权后获取并存储

### REQ-009：抽奖功能
- **描述**：用户可参与一次抽奖，随机获得10~500元礼券
- **优先级**：P0
- **抽奖规则**：
  - 60% 概率：10~50元
  - 30% 概率：51~200元
  - 9% 概率：201~499元
  - 1% 概率：500元
- **验收标准**：抽奖结果在上述范围内

### REQ-010：抽奖结果更新VIP卡礼券额度
- **描述**：抽奖完成后，礼券金额累加到VIP卡余额，返回首页后立即刷新显示
- **优先级**：P0
- **验收标准**：抽奖后返回首页，礼券余额 = 初始10元 + 抽奖金额

### REQ-011：仅可参与一次抽奖
- **描述**：每个用户只能参与一次抽奖，重复操作给出提示
- **优先级**：P0
- **验收标准**：已抽奖用户再次尝试时显示"已参与过抽奖"提示

### REQ-012：未登录不可抽奖
- **描述**：未登录用户点击抽奖时跳转到登录页，不强制登录
- **优先级**：P0
- **验收标准**：未登录点击抽奖跳转登录页，可选择"暂不参与"返回

### REQ-013：云开发模式
- **描述**：项目采用微信云开发，无需独立服务器
- **优先级**：P0
- **验收标准**：数据库、云函数均使用微信云开发平台

### REQ-014：中文注释和文档
- **描述**：所有代码包含中文注释，提供完整中文文档
- **优先级**：P2
- **验收标准**：代码文件均有中文注释，文档目录包含6份说明文档

## 4. 非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 页面加载时间 < 3秒，云函数响应 < 2秒 |
| 安全 | 数据库写操作全部由云函数执行，前端只读 |
| 兼容性 | 支持微信 8.0 及以上版本，iOS/Android 均可 |
| 可靠性 | 抽奖操作使用原子操作，保证不重复 |
