## 1. 云函数详细设计

### 1.1 `login` 云函数

**处理流程：**

```
1. cloud.getWXContext() → 获取 openid
2. 验证 openid 有效性
3. 调用 cloud.openapi.phonenumber.getPhoneNumber({ code: phoneCode }) → 解密手机号
4. usersCollection.where({ _openid: openid }).get() → 查询用户
5. 若用户存在：
   a. 有新手机号则更新
   b. 返回已有VIP卡信息，isNewUser=false
6. 若用户不存在：
   a. 调用 generateUniqueCardNumber() → 生成唯一卡号
   b. usersCollection.add() → 创建用户记录
   c. 返回新VIP卡信息，isNewUser=true
```

**卡号生成算法：**

```javascript
function generateCardNumber() {
  const num = Math.floor(Math.random() * 900000) + 100000;
  return `XJTU-${num}`;
}
// 最多重试5次确保唯一性，极端情况用时间戳后6位
```

### 1.2 `getLottery` 云函数

**处理流程：**

```
1. cloud.getWXContext() → 获取 openid
2. usersCollection.where({ _openid: openid }).get() → 查询用户
3. 若用户不存在：返回 code=-1（未登录）
4. 若 user.hasLottery === true：返回 code=1（已抽过）
5. generateLotteryAmount() → 生成随机金额
6. 原子操作：
   where({ _openid: openid, hasLottery: false })
   .update({ hasLottery: true, lotteryAmount, couponAmount: +lotteryAmount, ... })
7. 检查 updateResult.stats.updated：
   - > 0：原子操作成功，返回 code=0
   - === 0：并发导致已被更新，重新查询返回 code=1
```

**随机金额算法：**

```javascript
function generateLotteryAmount() {
  const rand = Math.random() * 100;
  if (rand < 60)  return Math.floor(Math.random() * 41) + 10;  // 10~50
  if (rand < 90)  return Math.floor(Math.random() * 150) + 51; // 51~200
  if (rand < 99)  return Math.floor(Math.random() * 299) + 201;// 201~499
  return 500;                                                    // 1% 概率500
}
```

### 1.3 `getUserInfo` 云函数

**处理流程：**

```
1. cloud.getWXContext() → 获取 openid
2. usersCollection.where({ _openid: openid }).get()
3. 若无结果：返回 code=1（未登录）
4. 返回 code=0 + 用户数据（cardNumber, couponAmount, hasLottery, lotteryAmount, giftType）
```

## 2. 前端页面详细设计

### 2.1 `app.js` 全局初始化

**scene参数解析逻辑（REQ-001, REQ-002）：**

```javascript
// App.onLaunch 中执行
if (options.query.scene) {
  const scene = decodeURIComponent(options.query.scene);
  if (scene === 'gift1' || scene === 'gift2') {
    this.globalData.giftType = scene;
  }
}
```

### 2.2 `index` 首页

**`onShow` 生命周期（每次显示时执行，REQ-010）：**

```javascript
onShow() {
  this.loadUserInfo(); // 调用getUserInfo刷新VIP卡
  this.setData({ giftType: app.globalData.giftType });
}
```

**抽奖按钮逻辑树（REQ-006, REQ-012）：**

```
onLotteryTap()
  ├── loading === true → 忽略（防重复点击）
  ├── isLoggedIn === false → navigateTo login页（REQ-012）
  ├── hasLottery === true → showToast('已参与过抽奖')
  └── 其他 → navigateTo lottery页
```

### 2.3 `login` 登录页

**`onGetPhoneNumber` 处理逻辑（REQ-007, REQ-008）：**

```javascript
onGetPhoneNumber(e) {
  if (e.detail.errMsg !== 'getPhoneNumber:ok') → 提示取消
  const phoneCode = e.detail.code
  callFunction('login', { phoneCode, giftType })
  → 成功 → 更新全局状态 → redirectTo lottery（未抽奖）或 navigateBack
  → 失败 → showToast错误提示
}
```

### 2.4 `lottery` 抽奖页

**并行执行设计（REQ-009）：**

```javascript
Promise.all([
  new Promise(resolve => setTimeout(resolve, 3000)), // CSS动画3秒
  wx.cloud.callFunction({ name: 'getLottery' })       // 云函数调用
]).then(([, cloudResult]) => {
  // 动画完成 + 结果返回后展示
  this.setData({ spinning: false, showResult: true, ... });
});
```

**返回首页触发刷新（REQ-010）：**

```javascript
onGoHome() {
  wx.navigateBack({ delta: 1 });
  // navigateBack 触发 index.onShow → getUserInfo 刷新VIP卡
}
```
