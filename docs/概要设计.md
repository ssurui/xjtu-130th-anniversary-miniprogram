版本：1.0
日期：2026年3月

## 1. 系统架构

本系统采用微信云开发架构，分为前端小程序层和后端云服务层。

```
┌─────────────────────────────────────────┐
│             微信客户端（前端）             │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  │
│  │  index  │  │  login  │  │ lottery │  │
│  │  首页   │  │  登录页  │  │  抽奖页  │  │
│  └─────────┘  └─────────┘  └─────────┘  │
└────────────────────┬────────────────────┘
                     │ wx.cloud.callFunction
┌────────────────────▼────────────────────┐
│          微信云开发（后端）               │
│  ┌───────────┐  ┌──────────┐  ┌───────┐ │
│  │   login   │  │getLottery│  │getUser│ │
│  │  云函数   │  │  云函数   │  │ Info  │ │
│  └─────┬─────┘  └────┬─────┘  └───┬───┘ │
│        └─────────────┼─────────────┘     │
│  ┌─────────────────▼────────────────┐    │
│  │      云数据库（users集合）         │    │
│  └────────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

## 2. 模块划分

### 2.1 前端模块

| 模块 | 文件路径 | 功能 |
|------|----------|------|
| 全局初始化 | `app.js` | 云开发初始化、scene参数解析 |
| 首页 | `pages/index/` | 展示VIP卡、礼品、抽奖入口 |
| 登录页 | `pages/login/` | 手机号授权登录 |
| 抽奖页 | `pages/lottery/` | 抽奖动画与结果展示 |

### 2.2 云函数模块

| 模块 | 云函数名 | 功能 |
|------|----------|------|
| 登录模块 | `login` | openid获取、手机号解密、用户创建 |
| 抽奖模块 | `getLottery` | 抽奖执行、防重复、余额更新 |
| 信息查询 | `getUserInfo` | VIP卡信息查询 |

## 3. 数据流设计

### 3.1 扫码入口流程（REQ-001, REQ-002）

```
用户扫码 → App.onLaunch解析scene → globalData.giftType赋值
→ 首页onShow读取giftType → 展示对应礼品
```

### 3.2 登录流程（REQ-007, REQ-008）

```
点击登录 → 微信授权弹窗 → 获取phoneCode
→ 调用login云函数 → getWXContext获取openid
→ 解密手机号 → 创建/更新用户记录 → 返回VIP卡信息
```

### 3.3 抽奖流程（REQ-009, REQ-010, REQ-011）

```
点击抽奖 → 启动CSS动画（并行）
→ 调用getLottery云函数
→ 原子操作检查hasLottery
→ 生成随机金额
→ 更新用户记录
→ 动画结束展示结果
→ 返回首页触发onShow → getUserInfo刷新VIP卡
```

## 4. 页面跳转关系

```
index（首页）
  ├── 未登录点击抽奖 → login（登录页）
  │     ├── 登录成功未抽奖 → lottery（抽奖页）
  │     │     └── 返回 → index（触发onShow刷新）
  │     └── 暂不参与 → 返回 index
  └── 已登录未抽奖点击抽奖 → lottery（抽奖页）
        └── 返回 → index（触发onShow刷新）
```

---

## 5. 安全设计

| 安全要点 | 实现方式 |
|----------|----------|
| 防SQL注入 | 使用云数据库SDK，无原生SQL拼接 |
| 防重复抽奖 | 原子操作 `where({hasLottery:false}).update()` |
| 数据写保护 | 数据库安全规则限制前端只读 |
| openid获取 | 通过 `getWXContext()` 在云函数内获取，前端无法伪造 |
| 手机号保护 | 后端解密，明文不经过前端传输 |
