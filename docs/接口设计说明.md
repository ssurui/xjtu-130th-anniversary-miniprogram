# 西安交通大学130周年校庆小程序 - 接口设计说明

版本：1.0
日期：2026年3月

---

## 1. 概述

本项目采用微信云开发模式，所有后端逻辑通过云函数实现。前端通过 `wx.cloud.callFunction()` 调用云函数。共设计3个云函数接口。

---

## 2. 通用规范

### 2.1 调用方式

```javascript
wx.cloud.callFunction({
  name: '云函数名称',
  data: { /* 入参 */ }
}).then(res => {
  const result = res.result; // 云函数返回值
});
```

### 2.2 通用返回格式

```json
{
  "code": 0,
  "message": "成功",
  "data": {}
}
```

| code值 | 含义 |
|--------|------|
| 0 | 成功 |
| 1 | 业务性失败（如已抽过奖、用户未登录） |
| -1 | 系统错误 |

---

## 3. 云函数接口详情

### 3.1 `login` - 一键登录

**功能**：获取openid和手机号，创建或更新用户记录，返回VIP卡信息。

**入参：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `phoneCode` | String | 是 | 微信获取手机号的动态令牌 |
| `giftType` | String | 否 | 礼品类型（`gift1`/`gift2`），默认`gift1` |

**出参：**

```json
{
  "code": 0,
  "data": {
    "cardNumber": "XJTU-123456",
    "couponAmount": 10,
    "hasLottery": false,
    "phoneNumber": "138****8888",
    "isNewUser": true
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `cardNumber` | String | VIP卡号，格式`XJTU-XXXXXX` |
| `couponAmount` | Number | 当前礼券余额（元） |
| `hasLottery` | Boolean | 是否已参与抽奖 |
| `phoneNumber` | String | 手机号 |
| `isNewUser` | Boolean | 是否为新用户 |

**错误返回：**

```json
{ "code": -1, "message": "手机号获取失败，请重试" }
```

---

### 3.2 `getLottery` - 执行抽奖

**功能**：执行抽奖，原子操作防并发重复，返回抽奖结果。

**入参**：无（openid由云函数自动获取）

**出参（成功）：**

```json
{
  "code": 0,
  "message": "抽奖成功",
  "data": {
    "lotteryAmount": 88,
    "couponAmount": 98,
    "cardNumber": "XJTU-123456"
  }
}
```

**出参（已抽过）：**

```json
{
  "code": 1,
  "message": "您已参与过抽奖",
  "data": {
    "lotteryAmount": 88,
    "couponAmount": 98,
    "cardNumber": "XJTU-123456"
  }
}
```

**抽奖概率：**

| 概率 | 金额范围 |
|------|---------|
| 60% | ¥10 ~ ¥50 |
| 30% | ¥51 ~ ¥200 |
| 9% | ¥201 ~ ¥499 |
| 1% | ¥500 |

**防重复机制**：使用 `where({hasLottery: false}).update()` 原子操作，确保并发情况下只执行一次。

---

### 3.3 `getUserInfo` - 获取用户信息

**功能**：查询当前用户的VIP卡信息，用于首页刷新显示。

**入参**：无

**出参（已登录）：**

```json
{
  "code": 0,
  "data": {
    "cardNumber": "XJTU-123456",
    "couponAmount": 98,
    "hasLottery": true,
    "lotteryAmount": 88,
    "giftType": "gift1",
    "phoneNumber": "138****8888"
  }
}
```

**出参（未登录）：**

```json
{ "code": 1, "message": "用户未登录" }
```

## 4. 数据库集合设计

**集合名称**：`users`

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | String | 自动生成 |
| `_openid` | String | 微信openid（云DB自动填充） |
| `phoneNumber` | String | 手机号明文 |
| `cardNumber` | String | VIP卡号 `XJTU-XXXXXX` |
| `couponAmount` | Number | 礼券总额（元），初始10 |
| `giftType` | String | `gift1` 或 `gift2` |
| `hasLottery` | Boolean | 是否已抽奖，初始false |
| `lotteryAmount` | Number | 抽奖金额，初始0 |
| `lotteryTime` | Date | 抽奖时间 |
| `createTime` | Date | 创建时间 |
| `updateTime` | Date | 最后更新时间 |

**安全规则**：前端只读（`doc._openid == auth.openid`），写操作全部由云函数完成。
